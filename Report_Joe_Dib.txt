Changes

I updated the greeting to return "Hello, World from Joe Dib!" and fixed
the test so it matches the application. I also added a test with another
name. The requirements file includes flake8, pytest, coverage and bandit.

The Python-CI-CD job loads Jenkinsfile_Joe_Dib from the main branch using
Pipeline script from SCM. Setup creates the virtual environment and installs
the dependencies. Lint checks app.py and the tests, then Test runs pytest.
The commands use the virtual environment's Python directly, so they do not
depend on shell activation.

I added a Coverage stage that runs the tests with coverage.py and generates
text, XML and HTML reports. The minimum coverage is set to 100%. The main
entry point is excluded from the unit coverage calculation; it is checked
separately when the deployed application runs.

The Security Scan stage runs Bandit on app.py. A finding causes the command
to fail and stops the pipeline before deployment.

Deploy runs deploy.sh to copy app.py into a local deployment directory next
to the Jenkins workspace. It runs that copy and checks the greeting. This
directory stays available after the workspace is cleaned. Jenkins saves the
test results, coverage reports, security report and deployment output before
cleanup.
